1. Strongest worth protecting
- The genuinely original core is the question “when does Higgs become a real PDF-constraining channel rather than only a top-to-Higgs transfer test?”; keep that central.
2. Weakest link
- Stage 2 overreaches because it never shows that frozen Higgs observables constrain gluon-`x` directions not already saturated by `t\bar t`, so the `>=15%` gain is not yet credible.
3. Claims needing evidence
- Add an explicit overlap test between Higgs and `t\bar t` response directions in the shared gluon latent (Fisher/PCA/score overlaps), and state which modes are new versus redundant.
4. Risk of the boldest idea
- The main risk is acceptable but must be named honestly: Higgs may add mostly nuisance decorrelation or transfer validation, not a new PDF constraint; that matters because those are different scientific claims.
5. What to do next
- Make Stage 2 a three-way test with nuisances fixed, PDF fixed, and both floating, then report whether any surviving gain sits on the Higgs-relevant gluon combination rather than nuisance-dominated modes before allowing Stage 3.
