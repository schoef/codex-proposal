Joint ttbar + ggH(H->gammagamma) fit: uncertainty map
Core thesis: the fit is justified if it constrains the same gluon-PDF directions in x~10^-2-10^-1; the main shared gain is PDF information, not broad cancellation of detector nuisances.
Shared experimental uncertainties (rank 4): luminosity (~1-2%, mature, easy to correlate if same run/experiment), beam energy/subpercent; pileup/object calibrations are only partly shared and likely subleading after channel-specific profiling.
Shared modeling/theory uncertainties (rank 1): gluon PDF basis by construction (few % inclusive, ~5-15% in rapidity/high-pT tails, exactly the POI), plus possibly alpha_s (~1-3%, mature but only defensible if varied consistently in PDF evolution and both hard processes).
Separate ttbar experimental uncertainties (rank 2): JES/JER, b tagging, lepton/MET, reconstruction/combinatorics; typically few % centrally and ~5-15% in differential tails, mature but numerous, so they will not cancel against H->gammagamma.
Separate ttbar modeling/theory uncertainties (rank 2): parton shower/ISR/FSR, color reconnection, top-mass scheme, ME-scale variation, b fragmentation; commonly few % inclusive and ~10% or worse in boosted/high-mttbar regions, still a major limitation for shape-level PDF extraction.
Separate ggH(H->gammagamma) experimental uncertainties (rank 3 today, rank 2 later): photon energy scale/resolution, photon ID/isolation, category migration, discrete-profiled continuum background; current CMS 13.6 TeV result is still statistics-dominated (74 +- 11 stat +5/-4 syst fb), so these are usually secondary globally but can dominate finely differential bins.
Separate ggH modeling/theory uncertainties (rank 3, but rank 1 in high-pT_H bins): ggH scale variation and acceptance, finite-mt/EFT breakdown, resummation/matching, production-mode admixture; ~3-6% in inclusive fiducial normalization and ~10-20% in hard-recoil tails, with the high-pT treatment still an active theory frontier rather than a solved nuisance model.
Impact ranking for a realistic first joint fit: 1) shared gluon-PDF directions, 2) ttbar modeling, 3) ggH high-pT theory if those bins are used aggressively, 4) ttbar experimental systematics, 5) ggH photon/background systematics, 6) shared luminosity/beam inputs.
Minimal staging that follows from this map: start with PDF-only sharing plus luminosity, keep all ttbar and ggH nuisance blocks separate, use ggH mainly through m_gg x {y_H,pT_H,coarse category}, and only enlarge the shared nuisance set if post-fit pulls show a genuine common mode rather than artificial over-correlation.
