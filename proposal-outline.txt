- Central vision: Build a CMS data-driven, unbinned SBI-PDF program in which dileptonic top events become the primary calibration sample for the gluon PDF at the detector level. The key claim is that CMS can extract PDF information directly from high-dimensional reconstructed events, rather than from a small set of unfolded histograms.

- Central vision: Use top-quark production as the common thread linking proton structure, precision Standard Model measurements, and SMEFT readiness. This keeps the proposal coherent: the same likelihood machinery, nuisance treatment, and event representations are reused across all measurements.

- Core measurement 1: Perform the flagship unbinned SBI-PDF determination of the gluon PDF from CMS `t tbar -> dilepton` data, starting from Run II and extending to Run III. This channel is experimentally clean, already mature in CMS, and probes the gluon over the `x` range most relevant for high-mass and boosted top production.

- Core measurement 1: Train surrogate likelihoods on detector-level observables that combine reconstructed top-system kinematics with lepton-level variables in a single event representation. The unbinned treatment avoids the information loss and correlation ambiguities of parallel binned measurements and should outperform standard differential inputs in systematic-dominated regimes.

- Core measurement 2: Add a targeted single-top component using final states sensitive to `b`-initiated top production, where perturbative `g -> b b` makes the rate and kinematics directly informative about the gluon and heavy-flavor content. This is the natural second lever arm because it stresses a different PDF projection than `t tbar` while staying within the same top-quark and CMS analysis ecosystem.

- Core measurement 2: Focus this extension on experimentally robust signatures, such as leptonic single-top topologies with explicit `b`-jet information and controlled backgrounds, rather than on an overly broad single-top program. The payoff is not statistics alone, but a sharper handle on how gluon information migrates into effective bottom-initiated channels and on whether the top-only PDF picture is self-consistent.

- Core measurement 3: Use differential Higgs production in gluon fusion as an in-situ validation and exploitation channel for the extracted gluon PDF, especially in overlapping `(x,Q^2)` regions reached by forward or high-`pT` Higgs bins. This turns the proposal from “one better PDF measurement” into a closed CMS measurement loop in which top data calibrate the PDF input needed by another flagship CMS program.

- Core measurement 3: The Higgs step is not a separate PDF fit but a stress test of portability: apply the top-constrained SBI-PDF posterior to Higgs observables and quantify where CMS can reduce reliance on external PDF information. This provides a concrete deliverable with immediate relevance for precision Higgs measurements.

- Methodological innovation: Put SBI-PDF at the center as a joint inference framework for PDF parameters and nuisance parameters using detector-level event likelihoods. The novelty is not ML by itself, but the combination of unbinned inference, realistic systematic profiling, and a PDF parameterization tailored to collider data.

- Methodological innovation: Exploit the polynomial structure shared by linear PDF models and quadratic SMEFT dependence to build a common surrogate architecture for PDF-only and PDF-plus-SMEFT fits. This creates a credible path toward simultaneous interpretation, instead of treating PDF uncertainties and EFT effects as separate downstream corrections.

- Methodological innovation: Include a focused SMEFT work package in which a small set of top-sensitive Wilson coefficients is profiled together with the gluon PDF in the same unbinned likelihood. The physics question is whether part of the apparent quadratic SMEFT response can be absorbed by PDF deformations, and conversely which observables remain genuinely discriminating once PDFs are floated.

- Experimental strategy: Anchor the full program in CMS reconstructed objects and published analysis logic, with `t tbar` dilepton as the first data application because of its purity, calibration maturity, and existing differential measurements. This is experimentally credible for a 2.5 MEUR project because it extends proven CMS workflows instead of requiring a new detector or a multi-channel global-fit effort from the start.

- Experimental strategy: Stage the project in three physics steps: first establish the unbinned gluon extraction in `t tbar`, then test heavy-flavor/gluon consistency with `b`-initiated single-top information, then propagate the result to Higgs observables and to a limited PDF-plus-SMEFT interpretation. Each step produces publishable physics while building directly on the previous one.

- Risk mitigation / fallback: If a full single-top implementation turns out slower than expected, keep the main proposal intact by delivering the `t tbar`-anchored gluon extraction plus the Higgs calibration study as the baseline program. The single-top component is then reduced to a targeted feasibility study on the most informative channel, rather than dropped completely.

- Risk mitigation / fallback: If simultaneous PDF-plus-SMEFT profiling is too ambitious for the first data release, perform it first in restricted parameter slices or on Asimov and control-region studies while preserving the same surrogate machinery. This keeps the proposal methodologically coherent and avoids overpromising on the most difficult interpretation layer.

- Expected impact: Deliver the first CMS-centered measurement program in which unbinned top data constrain the gluon PDF directly at detector level and feed back into another major LHC observable. If successful, this would establish a new mode of proton-structure inference inside an experiment rather than only through external global fits.

- Expected impact: The broader outcome is a reusable blueprint for future joint fits of PDFs, top-quark properties, and SMEFT effects with high-dimensional event information. That combination is scientifically timely, experimentally plausible, and distinctive enough to justify the proposed scale without drifting into an unfocused “all of proton structure” project.
