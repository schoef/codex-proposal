- Central vision: Build the first CMS experimental program that turns unbinned SBI-PDF into a practical, reusable proton-structure tool, with the gluon PDF extracted directly from CMS data rather than inherited only from external global fits. The core scientific claim is that high-dimensional detector-level likelihoods can turn standard top and Higgs measurements into a coherent in-house calibration chain for gluon-initiated physics.

- Core measurement 1: Unbinned SBI-PDF determination of the gluon PDF from CMS top-quark pair production in the dilepton channel at 13 TeV, using the full Run II dataset and then Run III extension. This is the anchor analysis because `ttbar` has broad sensitivity to the gluon PDF over roughly `x ~ 10^-2` to `0.5`, realistic CMS event reconstruction, and a strong case that unbinned multivariate observables outperform conventional differential bins.

- Why top quarks are indispensable: `ttbar` provides the cleanest experimentally credible CMS handle on the medium- to large-`x` gluon, where PDF uncertainties still matter for flagship LHC measurements. The same events also expose the interplay of top reconstruction, lepton observables, jet response, `b` tagging, and theory systematics, making them the right proving ground for uncertainty-aware unbinned inference.

- Detector-level strategy: Use reconstructed top, dilepton, jet and missing-momentum observables jointly in one unbinned likelihood instead of compressing the dataset to one- or two-dimensional histograms. The program should explicitly exploit the fact that unbinned SBI can combine top-level and lepton-level information from the same events without the correlation bottlenecks that weaken binned public results.

- Methodological innovation: Develop SBI-PDF as a CMS-ready inference framework with linear PDF models, event reweighting, and ML surrogates for the profiled likelihood including nuisance parameters. The novelty is not ML for its own sake, but an experimentally deployable likelihood model that keeps PDF sensitivity, detector effects, and systematic interpolation in one statistical object.

- Experimental realism: Start from CMS Run II `ttbar(2l)` selections and calibrations, then promote the method to Run II+III with the same analysis logic and improved detector modeling. The proposal should treat JES/JER, `b` tagging, luminosity, pileup, background contamination, scale variations, shower/hadronization modeling, and finite-simulation effects as first-class ingredients rather than afterthoughts.

- Core measurement 2: Propagate the `ttbar`-driven gluon-PDF determination to differential Higgs production through gluon fusion in CMS, especially `pT(H)` and `|y_H|` regions where the same gluon-`x` domain matters. This is the natural physics payoff because it tests whether an intra-CMS gluon calibration can materially reduce PDF limitations in a central Higgs channel.

- Why Higgs belongs in the same program: Higgs gluon fusion is not an extra topic, but the direct consumer of the improved gluon PDF extracted from top data. The program is coherent because top events determine the gluon PDF and Higgs measurements validate its usefulness on another gluon-dominated process with immediate impact on precision Higgs physics.

- Supporting measurement 3: Add an unbinned or weakly binned CMS electroweak control measurement that constrains the quark sector enough to stabilize the top-to-Higgs interpretation, for example high-mass or high-rapidity Drell-Yan. This is not meant to become a full quark-PDF project, but a targeted auxiliary channel that reduces degeneracies and strengthens the credibility of the gluon-focused program.

- Supporting measurement 4: Add a complementary top-based channel with different systematics, such as lepton+jets `ttbar` or single-top plus electroweak observables, once the dilepton analysis is mature. The purpose is to stress-test transferability of the unbinned SBI-PDF machinery across channels and to demonstrate that the extracted gluon information is robust against analysis choices.

- Deliverable logic: The program should release not only measurement points but an analysis-level likelihood representation that can be reused inside CMS and, where possible, exported in a compact surrogate form for later combinations. This is strategically important because the long-term impact comes from making unbinned PDF information portable, not from a single standalone paper.

- Theory and computing developments: Invest in NNLO-accurate or matched higher-order generators for the anchor channels, scalable event reweighting, and robust calibration/closure studies on Asimov and pseudo-data. This is a legitimate work package because the scientific promise of unbinned SBI-PDF depends on trustworthy modeling more than on larger neural networks.

- Coherence of the full program: The project has one spine only: use CMS top data to determine the gluon PDF with unbinned inference, validate the result in Higgs gluon fusion, and support the interpretation with a minimal auxiliary quark-sensitive control measurement. Every work package should be judged by whether it sharpens this top-to-gluon-to-Higgs calibration chain.

- Risk mitigation and fallback: If a full end-to-end unbinned fit with all nuisances proves too ambitious early on, the fallback is not to abandon the idea but to stage it: first demonstrate a publication-grade reduced-nuisance Run II result, then add full systematic groups and Run III. If Higgs propagation is slower than expected, the top-based gluon-PDF measurement remains a strong standalone deliverable with clear CMS value.

- Manpower plan: PI leads physics strategy, CMS integration, and final statistical architecture; 2 postdocs split between `ttbar`/Higgs phenomenology and ML-inference/systematics infrastructure; 2 PhD students focus on the anchor `ttbar` analysis and the auxiliary control-channel plus likelihood-release workflow; 1 research software engineer or dedicated scientific programmer supports production workflows, reproducibility, and scalable training. This is the right scale for a 4-6 year program because the bottleneck is simultaneous mastery of CMS analysis, theory systematics, and ML infrastructure.

- Budget logic for 2.5 MEUR: The budget is justified by sustained personnel, not hardware-heavy spending, because the main challenge is building and validating a new analysis methodology within CMS. A plausible envelope is personnel-dominated funding for the PI contribution, 2 postdocs, 2 PhD students, software/computing support, travel and collaboration exchange, and moderate computing resources on local and shared clusters.

- Expected impact: Scientifically, the project can deliver the first CMS data-driven unbinned gluon-PDF determination and show whether it improves precision for gluon-fusion Higgs predictions. Methodologically, it can establish a reusable path for bringing unbinned SBI with realistic systematics into mainstream LHC measurements and eventually into hybrid future PDF fits.
