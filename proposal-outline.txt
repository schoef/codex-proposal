- Central vision
  - Build a CMS real-data program in which unbinned SBI-PDF turns top-quark events into an internal calibration of the gluon sector, and then uses that calibration to unlock sharper Higgs and top-Higgs measurements. The narrative is one chain: constrain the gluon with top data, validate it in gluon-fusion Higgs, then use the stabilized proton input to attack a genuinely new-physics-sensitive measurement.
  - The proposal is physics-first: not a generic inference platform, but a sequence of concrete CMS measurements whose mutual consistency is itself part of the science. The central asset is that each add-on tests or exploits the same gluon-sensitive structure rather than opening a separate subfield.

- Core measurement 1: unbinned constrained-gluon extraction from CMS `ttbar(2l)`
  - The anchor is a real-data detector-level unbinned SBI-PDF measurement in CMS Run II dileptonic `ttbar` at `13 TeV`, with later Run III extension only after the Run II result is secure. This remains the decisive deliverable because `ttbar` directly probes the medium- and large-`x` gluon and already exists as a mature CMS precision channel.
  - The measurement uses correlated top-level, lepton-level, jet, and missing-momentum information in one likelihood rather than splitting the same events into loosely connected histograms. That is where unbinned inference matters qualitatively: it keeps the information flow from CMS detector objects to the gluon model intact.

- Core measurement 2: in-situ Higgs calibration with real CMS `ggH`
  - The first physics payoff is a real-data validation in differential gluon-fusion Higgs production, using CMS `H -> gamma gamma` and the observables `pT(H)` and `|y_H|`. This channel is experimentally clean, already measured by CMS, and directly tests whether the `ttbar`-derived gluon constraint reduces the PDF component in the kinematic region shared with `ggH`.
  - The point is stronger than a simple uncertainty propagation exercise: the proposal aims to show that one CMS dataset can calibrate the proton input needed by another CMS gluon-dominated measurement. If successful, this is an experimentally meaningful form of in-situ proton-structure control.

- New-physics spark: top-Higgs SMEFT after gluon calibration
  - The ambitious new physics project is a CMS top-Higgs interpretation in which SBI-PDF is extended from a constrained-gluon fit to a joint gluon-plus-SMEFT analysis in the top sector. This is well motivated because both the linear gluon model and SMEFT cross sections admit polynomial dependence, and recent literature shows that EFT effects can be partly reabsorbed by PDF freedom if the two are not treated together.
  - The natural target is differential `ttH` and, where useful, `tH` in CMS Run II data, because these processes are simultaneously sensitive to top-Higgs dynamics, gluon-initiated production, and interference patterns that are attractive for BSM interpretation. The program’s claim is not that PDFs and SMEFT are two separate topics, but that the former must be controlled to make the latter credible in high-information top-Higgs data.

- Why the add-ons belong together
  - `ttbar(2l)` determines the gluon where CMS has high-statistics top data; `ggH` tests whether that gluon information is physically useful in another gluon-dominated channel; `ttH/tH` then exploits the calibrated proton input in a measurement where PDF-SMEFT confusion is a real interpretational risk. This is one physics story, not a list.
  - The same logic gives the proposal its ambition: the program moves from proton structure, to Higgs precision, to BSM-sensitive top-Higgs dynamics without changing experimental ecosystem or inference philosophy. The synergy is that each stage reduces an ambiguity that would otherwise limit the next one.

- Supporting physics handle: single-top as a gluon-to-bottom cross-check
  - A single-top measurement, preferably `t`-channel and only as a focused follow-on, provides a useful orthogonal test because the bottom quark entering the five-flavor description is generated perturbatively from the gluon. Literature on single-top in PDF fits indicates sensitivity not only to quarks but also, partially, to the gluon, and to flavor-scheme choices.
  - In this proposal, single-top is not a second anchor program. It is a surgical cross-check on the perturbative `g -> b bbar` link that underlies the broader gluon story and a way to test whether the constrained-gluon picture remains consistent once bottom-initiated top production is brought into the same CMS framework.

- Methodological innovation in physics terms
  - The novelty is the combination of a restricted linear gluon-PDF parameterization, detector-level unbinned likelihood-ratio inference, and nuisance-aware profiling on real CMS measurements. This is distinct from both standard PDF fitting and generic machine-learning classification.
  - The same architecture is unusually well matched to a later SMEFT extension because the dependence on both gluon-basis coefficients and EFT coefficients is polynomial. That means the proposal can move from “measure the gluon better” to “separate proton-structure and new-physics effects better” without changing conceptual machinery.

- Experimental strategy
  - Keep the anchor analysis recognizably CMS: standard dilepton triggers, calibrated leptons and jets, `b`-tag categories, explicit Drell-Yan and single-top backgrounds, and nuisance classes that mirror established top measurements. The novelty lives in the unbinned inference layer, not in inventing an unfamiliar event selection.
  - Use real CMS differential Higgs measurements as they exist today, centered on `H -> gamma gamma`, so the in-situ validation has a concrete experimental landing point. Use the top-Higgs extension only after the constrained-gluon result is established, taking advantage of existing CMS `ttH` and CP-structure measurements rather than inventing a speculative future channel.
  - Keep theory-systematics ownership inside the physics program: generator accuracy, shower modeling, flavor-scheme dependence, and robustness of PDF-versus-SMEFT separation are scientific questions on the critical path. They are not service tasks and should be presented as measurement-defining issues.

- Staged physics program
  - Stage 1: publication-grade real-data unbinned constrained-gluon result in CMS `ttbar(2l)`, benchmarked against a strong binned baseline on the same dataset. This is the non-negotiable success condition.
  - Stage 2: real-data `ggH, H -> gamma gamma` validation showing whether the constrained-gluon result reduces the PDF component in `pT(H)` and `|y_H|`. This is the first cross-channel physics payoff.
  - Stage 3: joint gluon-plus-SMEFT interpretation in differential `ttH` and, where useful, `tH`, using the calibrated proton input to prevent BSM-sensitive effects from being misread as proton-structure freedom. This is the proposal’s distinctive “spark” and the place where the physics becomes genuinely more ambitious than a better PDF measurement.
  - Optional Stage 4: a high-mass `ttbar` or single-top stress test if needed to resolve residual large-`x` or flavor-scheme tensions. This remains contingency, not a co-equal pillar.

- Risk mitigation and fallback logic
  - If the full Higgs or SMEFT exploitation slips, the proposal still lands on a major result: the first real-data CMS detector-level unbinned constrained-gluon measurement from `ttbar(2l)`. That publication alone is grant-level success.
  - If quark-sector assumptions or flavor-scheme dependence become limiting, the first contingency is a focused single-top or high-mass Drell-Yan cross-check, not a broad control-channel expansion. If the joint SMEFT extension proves too ambitious in the proposal period, the program still delivers a calibrated-gluon likelihood and a sharply defined path to top-Higgs new-physics measurements.

- Expected impact
  - The near-term impact is a new route to extracting gluon information from rich CMS detector-level events and immediately testing its usefulness in Higgs production. That already changes the role of top data inside CMS precision physics.
  - The broader impact is conceptual: a path to disentangle proton structure from genuine new-physics effects in the top-Higgs sector using one coherent unbinned inference framework. If it works, the proposal does not just improve one measurement; it changes how CMS can connect top, Higgs, and BSM interpretation in the HL-LHC era.
