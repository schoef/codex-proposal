- Central question
  - Can CMS extract a useful constraint on the gluon PDF from real detector-level `ttbar(2l)` data with unbinned SBI-PDF, and can that constraint demonstrably improve one flagship gluon-initiated prediction? This is the single question that organizes the whole program.
  - The proposal is therefore not a broad PDF platform project, but a realism-first CMS measurement program with one anchor result and one sharply defined physics validation.

- Central vision
  - Build the first CMS analysis that uses uncertainty-aware unbinned inference on real `ttbar` dilepton events to determine the gluon component of the proton in a restricted functional space. The claim is targeted on purpose: this is not a full stand-alone proton-structure determination, but a CMS measurement of the gluon sector where top data are most informative.
  - The long-term significance is methodological and physical at once: rich detector-level events become usable for proton-structure inference, and the resulting constrained-gluon likelihood can be tested on a second gluon-dominated observable inside the same experiment.

- Why this is new
  - The novelty is not “ML for HEP” and not simply “top data for PDFs.” The real advance is the combination of a linear gluon-PDF parameterization, detector-level unbinned likelihood-ratio inference, and an explicit nuisance-aware statistical model in one CMS-grounded analysis chain.
  - The proposal should be judged against the current standard of low-dimensional binned measurements with Gaussianized covariance models. In the unbinned setting, one can use correlated top-level and lepton-level information simultaneously, constrain nuisances more directly in situ, and retain event-level likelihood information that standard histogram releases cannot provide.

- Anchor deliverable: real-data CMS `ttbar(2l)` gluon measurement
  - The non-negotiable deliverable is an unbinned SBI-PDF measurement using the CMS Run II `ttbar` dilepton dataset at `13 TeV`, with extension to Run III only after the core result is validated. The experiment is with real CMS data from the start; simulation serves calibration, training, closure, and systematic studies, not as the final scientific object.
  - The channel is chosen because it is experimentally mature, relatively clean, and genuinely sensitive to the gluon PDF in the kinematic range directly probed by CMS top data. It is also the channel where the case for combining reconstructed top observables and lepton-level observables in one detector-level inference is strongest.

- Concrete measurement definition
  - Data basis: CMS Run II dileptonic `ttbar` sample with standard two-lepton object definitions, `b`-tagged jets, missing transverse momentum, and established event selections. The proposal should stay close to a recognizable CMS top analysis so that the path to review and publication is credible.
  - Observable families: reconstructed `m(ttbar)`, `y(ttbar)`, `pT(ttbar)`, top and anti-top rapidities and transverse momenta, dilepton kinematics, and detector-level jet and missing-momentum information. The value of the unbinned approach is that these correlated features can enter one likelihood rather than being fragmented into several partially redundant histograms.
  - Publication target: a constrained-gluon measurement from real detector-level CMS `ttbar(2l)` data in a restricted gluon model space, benchmarked against a strong binned baseline using the same data. This needs to be stated as the primary publication endpoint, not one item among many.
  - CMS analysis path: implement the measurement as a recognizable CMS top analysis with standard dilepton triggers, nominal CMS lepton and jet calibrations, `b`-tag working points, explicit treatment of residual backgrounds such as Drell-Yan, single-top, and fake/nonprompt leptons, and nuisance parameters organized in the same classes that already govern precision top measurements. The novelty sits in the unbinned inference layer on top of this familiar analysis backbone, not in replacing the CMS analysis structure itself.

- Method validation and realism frontier
  - The existing local SBI-PDF work is the proof of concept: `POWHEG+PYTHIA+Delphes`, a linear gluon model, nuisance-aware surrogates, and Higgs uncertainty propagation. The proposal must say clearly that the frontier is now real-data integration and realism, not merely scaling up the proof of concept.
  - The central scientific task is therefore to close the gap between CMS-grounded simulation studies and a real-data measurement: realistic backgrounds, detector calibrations, nuisance validation, theory-model dependence, and robustness of the PDF–nuisance factorization ansatz all become named tasks rather than hidden assumptions.
  - Theory accuracy is not a downstream refinement. Generator choice, scale treatment, shower/hadronization dependence, and the path toward NNLO-matched descriptions are part of the credibility of the extracted gluon information and must be owned as a core milestone.

- Why unbinned inference is necessary here
  - The proposal should not oversell the gain as necessarily revolutionary in every metric. The stronger claim is qualitative: only the unbinned approach naturally permits simultaneous use of correlated detector-level top and lepton features, stronger in situ nuisance constraint, and a compact event-level likelihood product that a standard binned release cannot match.
  - Even if the total precision gain over an aggressive binned baseline were “only” at the `20–30%` level, the program would still be compelling because it would establish a new experimental route to proton-structure information from rich CMS event samples. The novelty lies in capability, not just in one headline number.

- Physics exploitation: one sharp Higgs validation target
  - The Higgs component is a validation of usefulness, not a second anchor program. Its purpose is to test whether the `ttbar`-derived constrained-gluon likelihood reduces the PDF component of the uncertainty in one clean differential gluon-fusion observable measured by CMS.
  - The proposal should therefore focus on one clearly defined `ggH` target in a single experimentally credible decay channel, rather than promising a broad Higgs precision program. The preferred target is differential `ggH` in `H -> gamma gamma` as a function of `pT(H)` and `|y_H|`, because the final state is clean, the kinematics are well reconstructed, and the PDF component can plausibly be isolated in data.
  - Success is demonstrating a robust reduction of the PDF uncertainty component for that target, not solving Higgs systematics in general.

- Contingency and stress tests
  - Keep only two visible follow-ons: a high-mass or boosted `ttbar` stress test of the constrained-gluon result in the larger-`x` region, and, only if needed, one surgical quark-sensitive control input based on high-mass or forward Drell-Yan. Both are subordinate to the anchor analysis and exist only to test robustness or resolve interpretation bottlenecks.

- Controlled treatment of non-gluon dependence
  - The proposal must state explicitly that the measurement constrains the gluon component in a restricted model space while treating the best-constrained quark sector as fixed to standard external inputs in the baseline fit. This is more accurate than speaking as if CMS were performing a full proton-structure extraction from `ttbar` alone.
  - Baseline light-quark and antiquark inputs are taken from standard external PDF sets, experimental and theory nuisance parameters are profiled in the likelihood, and robustness is quantified by repeating the inference under alternative quark-sector assumptions. The auxiliary Drell-Yan control input is activated only if those variations induce a material shift in the constrained-gluon result or in the `H -> gamma gamma` validation observable.

- Work-package hierarchy
  - Core measurement:
    deliver the real-data CMS Run II `ttbar(2l)` unbinned constrained-gluon result, with a publication-grade nuisance model and a strong binned comparison. This is the one deliverable the whole proposal must guarantee.
  - Method validation:
    establish closure on realistic pseudo-data, validate surrogate precision, test nuisance-constraining power, quantify sensitivity to theory choices, and demonstrate robustness under alternative gluon hypotheses. These studies are scientific outputs because they define when an unbinned proton-structure measurement is experimentally trustworthy.
  - Physics exploitation:
    propagate the constrained-gluon result to the selected `H -> gamma gamma` differential `ggH` target and, only if the core program is secure, optionally add one high-mass top extension or one surgical control input. This staging prevents the proposal from reading like several equal-weight analyses.

- Success criteria by stage
  - Stage 1:
    realistic closure and surrogate-validation studies on pseudo-data with publication-grade baseline nuisance classes for CMS `ttbar(2l)`. This establishes that the inference architecture is trustworthy before touching the headline physics claim.
  - Stage 2:
    blinded or control-region validation on real CMS Run II data, including background treatment, nuisance behavior, and stress tests of theory-model dependence. This is the gate from concept to measurement.
  - Stage 3:
    first real-data constrained-gluon result from CMS `ttbar(2l)`, benchmarked against a strong binned baseline and phrased as competitive in the kinematic region directly probed by the data. This is the main success condition for the proposal.
  - Stage 4:
    demonstration that the constrained-gluon result reduces the PDF component of the uncertainty for real-data differential `ggH` in `H -> gamma gamma` as a function of `pT(H)` and `|y_H|`. This is the physics-utility validation that closes the loop.
  - Optional Stage 5:
    one late-stage degeneracy-breaker or stress test, such as a Drell-Yan control input or a high-mass `ttbar` extension, if and only if the anchor result is already secure. This protects feasibility while leaving room for one creative follow-on.

- Feasibility and fallback logic
  - A full nuisance-aware unbinned CMS analysis is a major effort even without extra channels, so the proposal must treat the `ttbar(2l)` measurement as the only guaranteed major physics result. Manpower, milestones, and language should reflect that reality.
  - If the nuisance-factorization ansatz, surrogate precision, or theory-model dependence limits the full intended result, the credible fallback is still strong: a detector-level unbinned `ttbar` result with a reduced but publication-grade nuisance model and an internally usable constrained-gluon likelihood product. The Higgs propagation only proceeds once that basis is secure.
  - Publication logic should remain explicit: publication 1 is the real-data CMS `ttbar(2l)` constrained-gluon result; publication 2 is the `H -> gamma gamma` differential `ggH` validation only if publication 1 is secure. This makes the execution path concrete and protects the proposal against scope drift.
  - Claims about rivaling global fits must be carefully qualified. The right statement is that the measurement aims to be competitive with global constraints in the `x` range directly probed by CMS `ttbar` data, not that it replaces global PDF fitting.

- Resources and manpower
  - PI role: own the physics strategy, CMS integration, theory-systematics choices, and final statistical architecture. This cannot be delegated away because the scientific risk is in the interface between experimental realism and inference design.
  - Personnel: two postdocs and two PhD students are justified if the whole team is visibly concentrated on the anchor measurement, with Higgs exploitation and any auxiliary studies staged behind it. The budget should read as personnel-dominated support for one difficult CMS analysis plus its validation chain, not as funding for a broad software platform.
  - Technical support: dedicated scientific software effort is valuable, but it should be framed as enabling the anchor result and its reviewability inside CMS. Portable release formats are a strategic objective only if a concrete internal-use case is already in hand.

- Expected impact
  - Primary impact: the first real-data CMS measurement extracting gluon-sensitive proton-structure information from a detector-level unbinned top sample. That would be a distinctive experimental result even before any broader methodological uptake.
  - Secondary impact: a concrete demonstration that an internally constrained-gluon likelihood from CMS top data improves one flagship gluon-fusion prediction. This is the cleanest proof that the proton-structure information is physically useful.
