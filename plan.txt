1. Core thesis: perform a joint detector-level in-situ fit of `ttbar` and `ggH->gamma gamma` with one shared gluon latent, fixed once as the top-only Fisher-orthonormal basis of `delta ln g(x,Q0)` at `Q0=m_t`, sign-aligned to the window average on `x in [8e-3,8e-2]`, then DGLAP-evolved unchanged in all later tests.
2. Fully reproducible overlap toy: publish the exact Asimov setup `(luminosity, event yields, retained mode count k, nuisance priors, detector smearing, random seeds if pseudo-experiments are used)`, with one reference implementation that recomputes `F_t`, `F_H`, the projector into the retained top span, and the residual `R_H = F_H - F_H P_t (P_t^T F_H P_t)^+ P_t^T F_H` from scratch.
3. Higgs observable set is intentionally minimal: use unbinned `(m_gammagamma,|y_H|,pT_H)` where `m_gammagamma` is only the signal-background classifier, `|y_H|` is the cleanest detector-level proxy for the incoming parton-x asymmetry, and `pT_H` is the minimal second handle that separates recoil/topology and reduces fake overlap from rate-only information; do not add more Higgs observables unless they improve the overlap metric at fixed nuisance complexity.
4. Stage 1 closure: choose the smallest `k` retaining `>=95%` of the top-only Fisher trace in `x in [8e-3,8e-2]`, require coefficient recovery within `0.3 sigma`, 68% coverage in `[60%,76%]`, and `>=10%` gain over a matched binned baseline on `M_g = Var[ integral_W dx w(x) delta ln g(x,Q=m_H) ]`.
5. Stage 2 overlap test: classify Higgs as pure transfer validation if `lambda_max(R_H)<0.05*lambda_1(F_t)` or if adding Higgs improves `Var(M_g)` by `<10%`; classify it as a genuine new proton-structure direction only if a residual mode survives full `(PDF+nuisance)` profiling and improves `Var(M_g)` by `>=15%` beyond top-only.
6. Localization requirement: any surviving Higgs-added residual mode must have `>=80%` of its squared response norm in the explicit overlap window `x in [6e-3,3e-2]` at `Q=m_H`; if its support is broader or drifts outside this window, it is downgraded to a generic shape/nuisance direction rather than a localized gluon-information gain.
7. Mandatory nuisance scans: run `(i)` nuisances fixed/PDF floating, `(ii)` PDF fixed/nuisances floating, `(iii)` both floating, plus an alternate stronger benchmark with all Higgs shape-nuisance prior widths doubled and the Higgs background-slope/recoil-tail nuisance correlation set to `rho=0.8`; a residual mode counts only if present already in `(i)` and still present in the stronger `(iii)` benchmark.
8. Modelling-mismatch robustness: repeat the Higgs stage with pseudo-data generated from an unfitted recoil-tail distortion or background-shape misspecification; if the residual mode disappears or fails localization, the result is reclassified as modelling sensitivity, which is still informative because it defines the nuisance control needed before claiming true Higgs-top PDF synergy.
9. Extension gate and risk: only if the nominal, stronger-nuisance, and mismatch-injected tests all pass do we open the SMEFT branch `{O_tG, delta y_t, c_HG}`; the main risk is that Higgs adds no orthogonal localized gluon mode after profiling, but that still yields a clean publishable result that top events calibrate the relevant gluon latent and Higgs serves as a stringent transfer-validation channel rather than a source of new PDF directions.
