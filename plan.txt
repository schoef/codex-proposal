1. Core thesis

- Baseline paper: a minimum viable identifiability-and-closure study for sequential PDF transfer from `ttbar` to Higgs, with the rank-1 latent picture fixed throughout.
- Central question: can one physically meaningful one-dimensional gluon-PDF latent variable, learned from top-pair data, be propagated to one Higgs observable with predictive power that survives realistic nuisance treatment?
- Fixed baseline mapping:
- top control input: normalized `m_tt`;
- Higgs target output: normalized `|y_H|` in `ggF`;
- robustness cross-check only: absolute `m_tt`;
- optional refinement only if overlap fails: one minimal `|y_tt|` split.
- Baseline philosophy:
- keep the latent state rank-1 from the start to the end;
- do not silently promote the main claim to rank-2 if rank-1 struggles;
- treat failure as an informative boundary on sequential transfer, not as a reason to broaden scope opportunistically.

2. One explicit transferable gluon-PDF subspace

- Commit to one shared latent coefficient `z` corresponding to a rank-1 gluon-shape mode with support in the overlapping `x-Q^2` region probed by normalized `m_tt` and normalized `|y_H|`.
- Operational extraction:
- build PDF-response matrices `R_t` and `R_H` from replicas or Hessian eigenvector variations;
- whiten each observable by its non-PDF covariance to prevent raw bin scales from defining the mode;
- extract the leading shared direction from the whitened cross-response by SVD or an equivalent generalized eigenproblem;
- map that direction back to the gluon-PDF deformation and quote its `x` support and sign structure.
- Required interpretation product:
- one table linking `m_tt` bins to dominant `x` support, `|y_H|` bins to dominant `x` support, and the overlap window used to define the rank-1 mode.

3. Early response-geometry gate: absolute vs normalized `m_tt`

- This is the first hard gate, before the main closure campaign.
- Goal:
- show that the chosen shape baseline, normalized `m_tt`, still captures the Higgs-relevant shared mode seen in absolute `m_tt`, rather than merely being a convenient simplification.
- Procedure:
- extract the leading shared top-Higgs mode twice using the same Higgs target and the same PDF basis:
- once with absolute `m_tt`,
- once with normalized `m_tt`;
- compare the induced Higgs-side response vectors after whitening;
- decompose the absolute-`m_tt` response into a normalization-like component and a shape component, and check whether the normalized-spectrum mode aligns with the shape component;
- report the prior Higgs PDF variance captured by each extracted mode.
- Pre-declared survival metrics:
- cosine similarity between the Higgs-side response vectors above `0.9`;
- normalized `m_tt` captures at least `80%` of the Higgs variance captured by absolute `m_tt`;
- the residual difference is dominated by the projected-out normalization direction rather than by a rotation into a distinct Higgs-relevant shape.
- Interpretation rule:
- if these conditions hold, the baseline claim becomes: normalization removes mostly normalization information while preserving the Higgs-relevant shared shape mode;
- if the cosine stays high but the variance fraction drops appreciably, keep normalized `m_tt` as the baseline but explicitly downgrade the expected impact to "clean but sensitivity-limited";
- if the cosine fails or the normalized mode clearly rotates away from the absolute-mode shape component, state that the chosen shape baseline is not adequate and the baseline program fails on observables, rather than quietly changing baselines.
- Deliverable:
- one figure with absolute-vs-normalized Higgs-side response geometry;
- one table with cosine, variance-capture ratio, and normalization-projection fraction.

4. Sufficiency thresholds: justify them or downgrade them explicitly

- The sufficiency test compares:
- rank-1 sequential posterior `p(y_H | p(z | y_t), model)`;
- reference posterior `p(y_H | y_t, model_full)` built from the same generative setup but allowing the retained reference PDF subspace.
- Baseline working tolerances for calling rank-1 "sufficient":
- Higgs posterior mean shift in each bin within `0.25` of the reference posterior standard deviation;
- Higgs posterior variance within `10%` relative difference;
- proper predictive score degraded by no more than `10%`.
- Justification of these numbers:
- `0.25 sigma` is tight enough that omitted PDF structure remains clearly subdominant to the quoted Higgs posterior width, so "rank-1 sufficient" does not collapse into "roughly similar by eye";
- `10%` on variance is a practical bound for saying the compressed latent state preserves the uncertainty scale, not just the central trend;
- `10%` on predictive score prevents the rank-1 summary from passing while distorting posterior shape or tails.
- Explicit downgrade rule:
- if pilot pseudo-data studies show that these thresholds are not stable enough to distinguish genuine approximation error from finite-ensemble noise, do not claim sufficiency at those levels;
- instead relabel the main output as "rank-1 approximation quality quantified";
- one weaker tolerance set may be adopted once, before the main scan, at `0.33 sigma` on means and `15%` on variance and predictive score;
- if even the weaker set is not defensible, abandon pass/fail sufficiency language and report only continuous approximation metrics.
- Anti-p-hacking rule:
- thresholds must be frozen before the main held-out Higgs closure study;
- no retuning based on favorable Higgs outcomes.
- Reporting rule:
- always quote the continuous metrics, even if the pass/fail label is used.

5. Make the nuisance partition fully operational

- The sequential factorization to test is:
- `p(y_t, y_H | z, c, u_t, u_H) = p(y_t | z, c, u_t) p(y_H | z, c, u_H)`;
- prior factorization at baseline:
- `p(z, c, u_t, u_H) = p(z) p(c) p(u_t) p(u_H)`.
- The partition is not rhetorical. Each nuisance source must be assigned to one of three blocks and handled accordingly.

- Top-only block `u_t`:
- examples: top acceptance and reconstruction, top-background normalizations, top unfolding / response effects, top-only shower or color-reconnection components, top-specific detector effects that do not enter the Higgs measurement;
- action: include in the top likelihood, profile or marginalize there, and do not propagate them.

- Higgs-only block `u_H`:
- examples: Higgs category migrations, Higgs-channel background shapes, Higgs-specific efficiencies, Higgs recoil or resolution effects not shared with the top observable;
- action: include only in the Higgs likelihood and do not claim they are constrained by top data.

- Common block `c`:
- sub-block `c_norm`: integrated luminosity and other overall normalization nuisances;
- sub-block `c_pdf,res`: residual shared PDF-theory ingredients other than `z`, such as higher-rank PDF directions or shared `alpha_s` response if not frozen;
- sub-block `c_th`: common perturbative production effects that can shape both `ttbar` and `ggF`, such as scale-variation families;
- sub-block `c_det`: detector-calibration classes that can survive normalization and appear in both measurements, especially JES/JER, `b` tagging, and lepton efficiencies if they are genuinely shared.

- Operational workflow for the partition:
- Step 1: build a nuisance inventory table with one row per source and columns:
- physical origin;
- affects top?;
- affects Higgs?;
- survives normalization?;
- candidate block `u_t`, `u_H`, or `c`;
- propagated in baseline yes/no;
- Step 2: for each candidate common nuisance, compute whitened response vectors in top and Higgs spaces and compare them to the PDF mode;
- Step 3: promote a nuisance class into propagated `c` only if its aligned top-Higgs distortion is non-negligible relative to the rank-1 PDF mode;
- Step 4: otherwise leave it in stress-test mode and document why it is excluded from the baseline propagated state.

- Concrete promotion rule for common nuisances:
- if a nuisance class induces a top-Higgs aligned distortion with cosine above `0.7` to the PDF shared mode and norm at least `30%` of that mode on the whitened scale, it cannot be dismissed as negligible;
- then either propagate it jointly in `c` or narrow the measurement definition until the effect is reduced.
- If it fails that rule, keep it out of the propagated baseline state but include it in the validity audit.

- Baseline choices implied by this rule:
- `c_norm` is excluded from the main propagated claim because the baseline uses normalized spectra; it reappears only in the absolute-`m_tt` cross-check;
- `c_pdf,res` belongs in the reference model used for the sufficiency audit, even if it is not propagated in the rank-1 baseline;
- `c_th` and `c_det` are first treated as correlated stress-test families, then promoted only if their shared distortion competes materially with the PDF mode.

6. Minimal scientific claim

- Positive claim:
- one identifiable gluon-PDF direction exists, normalized `m_tt` constrains it, and it explains a material fraction of the prior PDF variance of normalized `|y_H|`.
- Stronger claim, only if the thresholded sufficiency test survives:
- the posterior of the single latent coefficient `z`, possibly together with an explicitly retained low-dimensional common block `c`, is approximately sufficient for the Higgs posterior change induced by top data.
- Negative claim:
- if the geometry gate fails, if the nuisance partition exposes unmodeled common structure, or if the sufficiency audit fails, then the baseline sequential rank-1 transfer picture is not validated.

7. Subtasks of the core thesis

- Subtask A: overlap and observable freeze
- map the `x-Q^2` support of normalized `m_tt` and normalized `|y_H|`;
- decide whether inclusive `m_tt` is adequate or whether one minimal `|y_tt|` split is needed.

- Subtask B: absolute-vs-normalized `m_tt` geometry gate
- run the early survival study described above;
- freeze the baseline only if the normalized-shape mode still captures the Higgs-relevant shared shape.

- Subtask C: rank-1 mode extraction
- build the whitened response matrices;
- extract the shared mode;
- test stability under PDF basis choice and mild rebinning.

- Subtask D: operational nuisance partition
- build the nuisance inventory table;
- classify each source into top-only, Higgs-only, or common;
- run one-at-a-time and grouped response comparisons to decide what must enter `c`.

- Subtask E: `ttbar` identifiability fit
- fit `z` in pseudo-data with the frozen top nuisance model;
- measure bias, calibration, and contraction.

- Subtask F: rank-1 sufficiency audit
- compare the rank-1 sequential Higgs posterior to a reference posterior that retains the richer shared PDF space and any required propagated common block.

- Subtask G: sequential Higgs closure
- propagate the top posterior on `z` alone, or on `(z, c)` if promotion was required, into normalized `|y_H|`;
- check calibration, bin-wise shifts, and uncertainty reduction against held-out truth.

- Subtask H: realism audit
- re-run closure under expanded nuisance and theory settings to test whether the sequential factorization remains adequate.

8. Concrete staged execution plan

- Stage 0: freeze the baseline scope
- baseline remains normalized `m_tt` -> normalized `|y_H|`;
- rank-1 latent variable remains fixed;
- absolute `m_tt` is a gate and robustness cross-check, not an alternate baseline;
- not in baseline: `pT(H)`, single-top, inclusive jets, SMEFT.
- Main risk:
- the baseline is too lean.
- Why acceptable:
- the first paper needs a falsifiable and interpretable chain, not maximum breadth.
- Fallback:
- keep follow-up channels explicitly outside the baseline paper.

- Stage 1: early response-geometry gate
- run absolute-vs-normalized `m_tt` comparisons immediately;
- decide whether normalized `m_tt` preserves the Higgs-relevant shared mode.
- Main risk:
- normalization removes the useful mode, not just normalization information.
- Why acceptable:
- this is a cheap and decisive early kill test.
- Fallback:
- if it fails, publish the failure of the shape-only baseline rather than broadening scope.

- Stage 2: derive the rank-1 shared mode
- extract the leading shared PDF direction and quote Higgs-variance capture;
- report the continuous variance-capture number, not just pass/fail.
- Materiality benchmark:
- roughly one-third Higgs prior PDF variance captured is "material" for a standalone baseline paper, but this is a benchmark, not a theorem.
- Main risk:
- the common structure is too diffuse to compress.
- Fallback:
- publish a quantitative upper bound on rank-1 transferability.

- Stage 3: make the nuisance partition operational
- complete the nuisance inventory;
- test candidate common nuisances individually and in small groups;
- decide what must enter propagated `c`.
- Main risk:
- shared detector or perturbative effects compete with the PDF mode.
- Why acceptable:
- exposing that competition is central to the validity claim.
- Fallback:
- either promote the non-negligible shared block into `(z, c)` or explicitly downgrade the claim to a PDF-only idealization.

- Stage 4: `ttbar` identifiability closure
- fit `z` with the frozen nuisance model;
- quote contraction, bias, and calibration.
- Learnability benchmark:
- a visible contraction is desirable, but the paper should report the actual contraction factor rather than enforce an arbitrary minimum.
- Main risk:
- the mode exists geometrically but is not inferentially learnable.
- Fallback:
- narrow the result to geometry plus a no-go inference statement.

- Stage 5: sufficiency audit
- compare rank-1 sequential propagation against the richer reference model under the frozen threshold policy;
- if needed, activate the explicit downgrade path rather than stretching the meaning of "sufficient."
- Main risk:
- the leading mode is real but not sufficient.
- Why acceptable:
- that boundary is scientifically valuable.
- Fallback:
- report rank-1 as a quantified approximation only.

- Stage 6: sequential Higgs closure
- propagate only the allowed latent state from top to Higgs;
- test calibration and predicted bin pattern in held-out pseudo-data.
- Aspirational impact range:
- a `10-20%` Higgs-variance reduction is nice but not required for publication;
- even a smaller but robust and well-calibrated transfer is scientifically useful.
- Main risk:
- the mode is learnable in top but too weakly relevant for Higgs.
- Fallback:
- publish the practical ceiling on top-to-Higgs transfer for `|y_H|`.

- Stage 7: validity audit under realism
- enrich nuisance and theory settings and compare sequential closure with a matched joint construction;
- verify that the main conclusion survives without hidden correlations.
- Main risk:
- sequential transfer works only in a PDF-only toy limit.
- Fallback:
- convert the result into a clear no-go boundary and identify which shared nuisance blocks must be promoted in future work.

9. Explicit validity criteria

- V1: pre-definition
- the rank-1 mode definition, geometry-gate metrics, nuisance-promotion rule, and sufficiency thresholds are frozen before the main closure study.

- V2: geometry survival
- normalized `m_tt` demonstrably preserves the Higgs-relevant shared shape mode seen in absolute `m_tt`.

- V3: operational partition
- every important nuisance source is assigned to `u_t`, `u_H`, or `c`, with a documented action and a response-based justification.

- V4: inferential learnability
- `z` is identifiable from normalized `m_tt` once the frozen top nuisance model is included.

- V5: rank-1 sufficiency or honest downgrade
- the rank-1 latent state passes the frozen tolerances, or the plan explicitly downgrades the claim to quantified approximation quality.

- V6: calibration
- the sequential Higgs posterior is calibrated in held-out closure.

- V7: stability
- the qualitative conclusion does not flip under mild rebinning, PDF basis changes, or modest perturbative variations.

10. Concrete synergy items

- Synergy item 1:
- the program connects response geometry to posterior sufficiency, rather than stopping at correlation plots.

- Synergy item 2:
- top data act as the in-situ control system for a shared gluon direction, while Higgs data test whether that direction remains predictive after evolution and nuisance-aware projection.

- Synergy item 3:
- the absolute-vs-normalized `m_tt` gate turns a methodological convenience into a falsifiable physics statement about what normalization removes.

- Synergy item 4:
- the operational nuisance partition makes the sequential claim experimentally legible: it states exactly which shared effects are propagated, excluded, stress-tested, or promoted.

11. Risk assessment and fallback

- Risk: normalized `m_tt` is too delocalized in `x` or too shape-insensitive.
- Why acceptable:
- the overlap study and geometry gate expose this early.
- Fallback:
- allow only the minimal `|y_tt|` split; otherwise treat the baseline as falsified.

- Risk: absolute `m_tt` and normalized `m_tt` probe different Higgs-relevant directions.
- Why acceptable:
- this is precisely the issue the professor asked to test early.
- Fallback:
- downgrade or terminate the shape-baseline claim instead of silently replacing the observable.

- Risk: the sufficiency thresholds are not persuasive.
- Why acceptable:
- the plan now provides both a justification and an explicit downgrade path.
- Fallback:
- report only continuous approximation metrics and avoid binary sufficiency claims.

- Risk: the nuisance partition reveals a non-negligible common block beyond the PDF mode.
- Why acceptable:
- that result sharpens what sequential transfer would actually need to propagate.
- Fallback:
- promote the block into `c` if still low-dimensional, or downgrade the result to a conditional PDF-only study.

- Risk: rank-1 is stable geometrically but not sufficient statistically.
- Why acceptable:
- that still distinguishes a leading shared direction from an adequate latent summary.
- Fallback:
- publish rank-1 as a diagnostic mode with quantified limitations.

- Risk: Higgs `|y_H|` is too weakly sensitive for large visible gains.
- Why acceptable:
- it remains the cleanest first target for validating the transfer logic.
- Fallback:
- frame the paper as a validity-and-ceiling result, not an optimization claim.

12. Follow-up only if the baseline succeeds

- First follow-up:
- extend the validated latent-state logic to `pT(H)` and test whether transfer survives stronger recoil and radiation sensitivity.

- Second follow-up:
- add a second top observable family only if it contributes a genuinely orthogonal shared direction beyond the validated rank-1 baseline.

- Third follow-up:
- only after the Standard Model baseline is validated, consider single-top, inclusive jets, or SMEFT as structured extensions rather than baseline ingredients.
